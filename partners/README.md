# Partner library

Other teams' autos, by team number, saved by AutoTool (Partner tab or Manage → Partner library).

    partners/<team>/team.json        team name, robot size and speed, notes
    partners/<team>/v-<time>.json    one route as seen at an event, with where it came from and notes
    partners/<team>/v-<time>.pp      the Pedro visualizer file it was imported from, as it was

Commit this folder to share it with the team. AutoTool never commits or pushes it.
